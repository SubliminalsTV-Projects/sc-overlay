# uses profanity amongst other adults. I don't need to ban for that."

# So this file is SLURS AND HATE SPEECH ONLY. Ordinary profanity lives in wordlist-censor.txt
# and is asterisked in place; nobody is banned for it. A term in neither file never fires at all.

# HOW TO EDIT: one term per line, `#` comments a line out. Matching is case-insensitive and on
# WORD BOUNDARIES (see automod.mjs), never substrings — "spic" cannot fire on "spice", "coon"
# cannot fire on "raccoon", "retard" cannot fire on "retardant". A term with spaces matches
# across any run of whitespace.
#
# 🔴 A BAN HERE HITS A REAL, NAMED PERSON. Chat is RSI-verified, which is what makes a ban stick
# and is also what makes a false one expensive. Everything below is either an unambiguous slur or
# an unambiguous hate slogan; the judgement calls are commented out at the bottom with the reason,
# so a decision to enable one is a decision someone made rather than a line nobody noticed.
